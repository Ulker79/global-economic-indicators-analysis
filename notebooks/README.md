This folder contains the full analytical workflow developed in Google Colab (Jupyter Notebook environment).

The notebook includes:
- Data cleaning and preprocessing
- Column renaming and standardization
- Missing value imputation (median)
- Feature engineering
- Log transformations
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Boxplot, heatmap, and violin plot visualizations
- Hypothesis testing:
  - Paired t-test
  - Pearson correlation analysis
