This folder contains pivot table analysis built in Microsoft Excel to support structured economic comparisons.
Three pivot-based analytical sheets were created:

## 1. Trade Balance Analysis
- Average Imports by Country
- Average Exports by Country
- Comparative bar chart visualization
- Country-level trade pattern comparison

## 2. GNI vs GDP Comparison
- Average GNI by Country
- Average GDP by Country
- Line chart comparison
- High-GDP country performance analysis

## 3. Population vs GDP Analysis
- Average Population by Country
- Average GDP by Country
- Comparative visual representation
- Population scale vs economic output insights

The pivot tables were used to:
- Validate trends identified in Python analysis
- Provide structured summary comparisons
- Support dashboard insights with tabular validation
