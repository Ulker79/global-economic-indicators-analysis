# Power BI Dashboard
This folder contains the interactive Power BI dashboard file (.pbix).
The dashboard is structured into three analytical pages:

---

## Page 1 – Global Economic Overview
- Global GDP (2021)
- Total countries and population metrics
- Top 10 countries by GDP
- EU consumption comparison (Government vs Household)
- Exports vs Imports comparison
- Global GDP map visualization

---

## Page 2 – Sector Analysis & Trends
- Sector share breakdown
- Industry, Agriculture, and Other Activities comparison
- Time-series sector trend analysis (2010–2020)
- Country-level sector distribution

---

## Page 3 – Country-Level Analysis (Azerbaijan)
- GDP and population metrics
- Exports vs Imports over time
- Household vs Government consumption comparison
- Population vs GDP per capita trends
